# Data Directory

This directory is intentionally kept free of bundled market datasets.

Reasons:

- financial data licenses and redistribution terms vary by provider;
- market data can become stale quickly;
- API-based retrieval improves reproducibility when provider terms permit it.

Course examples either generate deterministic synthetic data or retrieve data directly from documented providers.

Do not commit API keys, credentials, proprietary Bloomberg data, or datasets whose license prohibits redistribution.
